# command line cheat sheet
---
## creating a folder
the command to create a **folder** is mdkdir and the name of your choice
for example:
mkdir folder22

## creating a file
the command to *create* a *file* is touch and the name of your choice .txt or .md

for example

'''cd folder22

touch file.txt\

touch file.md'''

---
## changing a directory or going back a directory
the command to **change a directory** is cd and then the name of the folder
for example

cd folder22

the command to go **back** a directory is

cd..
## the command to show a current directory is 
pwd

this command is used to see your current location
## the command to list directory files 
is

output:folder22 file.txt file.md
## command to create a detailed file list 
is  -la
